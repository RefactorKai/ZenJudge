# Quiet Run

A device records one bit per minute: 0 means quiet and 1 means busy. Find the longest uninterrupted run of quiet minutes.

## Input
The first line contains N (1 <= N <= 1000). The second line contains N values, each either 0 or 1.

## Output
Print the length of the longest consecutive run of zeros. Print 0 if there are no quiet minutes.

## Example
Input:
```text
7
1 0 0 1 0 0 0
```
Output:
```text
3
```
