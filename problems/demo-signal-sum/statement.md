# Signal Sum

A small sensor sends a batch of signed measurements. Print their total.

## Input
The first line contains an integer N (1 <= N <= 1000). The second line contains N integers, each between -1000000 and 1000000.

## Output
Print the sum as one integer.

## Example
Input:
```text
4
6 -2 0 9
```
Output:
```text
13
```
