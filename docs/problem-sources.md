# Problem sources and redistribution

The default release includes only the three original `demo-*` packs written for ZenJudge. Their statements and test fixtures were not copied from an external problem platform. They are distributed with the project under GPL-3.0-only.

The five legacy local packs are preserved in the developer's working folder and explicitly excluded from publication. They are not relabeled as original demo content.

## CSES

The [official introduction](https://cses.fi/problemset/text/2433) identifies the problem set's license as **Creative Commons BY-NC-SA 4.0**. The [license terms](https://creativecommons.org/licenses/by-nc-sa/4.0/) include attribution, noncommercial use and share-alike conditions. This is distinct from the GPLv3 license for ZenJudge's application code.

The [public problem index](https://cses.fi/problemset/) and introduction were fetched during release preparation to verify this. No CSES statements, private testcases, submissions or solutions are bundled in the core release. A future optional content pack must retain its source, attribution, modification record and separate license rather than claiming it is GPL-licensed application material. Public sample cases do not establish correctness against CSES's private judge data.

## Blind 75

Blind 75 is a curated practice list by Yangshun Tay. The [Tech Interview Handbook](https://github.com/yangshun/tech-interview-handbook) repository uses [MIT](https://github.com/yangshun/tech-interview-handbook/blob/main/LICENSE), including a notice-retention condition.

That repository license does not establish redistribution rights for the problem statements hosted on linked platforms such as LeetCode. ZenJudge therefore links to the original study resources rather than copying their statements into its demo packs. No endorsement or affiliation is claimed.

The download capability used to inspect a public page is not itself permission to redistribute that page's contents.
