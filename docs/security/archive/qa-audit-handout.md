# Archived QA handout — claims superseded 31 October 2026

Earlier ratings and statements of complete attack prevention are withdrawn. Passing the former suites did not demonstrate file/network isolation or fail-closed execution. Some probes had unsafe side effects or accepted weak outcomes; the old stress telemetry included constants rather than measurements.

The current host execution implementation is retired, and compilation/execution requests are rejected. No secure replacement boundary has been implemented. See [verified remediation and remaining gates](../remediation.md), [AppContainer investigation](../../appcontainer-worker.md), and [publication decisions](../../releasing.md).

The original text is preserved only in the local, publication-excluded `.audit-work/baseline/` backup. It is not current evidence. Only results explicitly recorded in the remediation report are claimed; ignored/retired execution tests are never counted as successful containment tests.
