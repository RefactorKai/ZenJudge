# Security remediation — 31 October 2026 (Asia/Bangkok)

This is the historical security audit/remediation record. Later source-preview preparation uses owner-selected GPLv3, original demo packs and replacement demo artwork. See [release instructions](../releasing.md) and [content provenance](../provenance.md). Test counts and third-party content findings below describe their original audited snapshots; the current demo-only checkout has no legacy execution tests.

Execution is **unavailable**, by the owner's explicit choice while an AppContainer worker is investigated. The host compiler/runtime implementation, low-integrity token code, Job Object code and unsafe stress harness were retired. There is no fallback or opt-in switch. This is an enforced rejection policy, **not a completed containment boundary** and not a claim of secure grading.

The three supplied audit artifacts were read before implementation. All 59 source/config/content files captured in the pre-edit backup matched their corresponding audit evidence hashes. There was no Git repository/history. The original files were preserved in `.audit-work/baseline/`, with a hash manifest. No live database, submission, note or WebView settings store was opened, modified or deleted during this work. No source was published/uploaded, repository visibility changed, license selected or content ownership asserted. Public npm metadata/packages and an advisory check were fetched; those requests disclosed dependency identifiers, not application source/data.

Validation performed on the final source:

- Rust safe suite: **18 passed, 8 explicitly ignored legacy execution tests**, serially in fresh `.audit-work/test-temp-*` directories. Two streak unit tests cover local-day boundaries, duplicates, gaps, yesterday grace, future/invalid timestamps and streaks beyond 30 days. Eleven remediation tests include real registered Tauri submission handlers, native notes persistence, a disposable Windows junction, bounded decompression, migration/WAL import, fixture uniqueness and comparator limits.
- Strict `cargo clippy --all-targets -- -D warnings` and `cargo fmt --all -- --check`: passed. Windows mock-runtime integration executables needed an explicit Common Controls v6 manifest; this fixes a test loader error without modifying OS settings.
- TypeScript and Vite production frontend build: passed. Large Monaco bundle warning remains. Actual Tauri debug desktop binary built with the disposable frontend and no bundle/installer; it was never launched against live data. Problems were copied under the build's resource directory.
- Markdown/math SSR, headless App-controller, and real-Monaco workspace regressions: passed. The controller test uses the actual `App.tsx` with synthetic IPC and simplified child components; it exercises history restore across languages, draft switching/persistence and reversed asynchronous responses. The workspace test uses the built frontend and actual child components under production CSP with synthetic native responses; failed note saves retain their text and can be retried, and both hotkeys use current callbacks/state.
- All 27 fixture answers independently checked using the reviewed audit checker pointed at the remediated packs; no contract violations. The application loader is separately covered by Rust tests.
- `npm ls katex --all`: deduplicated 0.19.1. `npm audit --json --ignore-scripts`: zero advisories. No automatic major dependency downgrades.
- Source-only allowlist and heuristic credential scan: generated locally by `scripts/source-manifest.py`; no export/upload. The manifest must be rerun after changes and reviewed before publication. No Git history exists to inspect.

Build/test outputs and logs are deliberately retained under `.audit-work/` for local review. The sandbox initially denied Tauri/Vite/rustfmt canonicalization and npm DNS; host-access retries succeeded. Initial failures were not counted as successful validation. The first mock-runtime test binary failed to load until its manifest was corrected; no assertions were relaxed to fix that failure.
